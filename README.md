# Code Brokers

**Private code and its history, licensed to AI labs. You keep ownership.**

AI labs want to learn from real software: how it was actually built, not just the finished code.
Years of commits, pull requests, tests and docs are what make a codebase valuable to them.

We help owners license their private codebases, with that history, to AI labs. It's a
non-exclusive licence, so you keep the code and carry on using it. We're a broker, so we never
buy the code ourselves.

## Tools

- **[unreal-repo-scan](https://github.com/code-brokers/unreal-repo-scan)**: run it on your Unreal
  Engine project to get a metadata-only summary (C++ lines, Blueprint and asset counts, the
  C++/Blueprint split, version-control history). No code leaves your machine, and you read the
  report before you share it.
